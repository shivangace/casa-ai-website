DPDP Act 2023
Digital Personal Data Protection Act 2023 · India

India's comprehensive data protection law. CASA-AI enforces the four most critical sections at agent runtime — preventing violations before they can occur, not detecting them after.

ENTERPRISE+ Tier No competitor has this
DPDP S.4/6
Lawful Processing: PII processing blocked unless explicit purpose is declared and matches the approved purposes in the agent's session profile.
DPDP S.8
Data Minimisation: Blocks agent actions that extract or transmit PII fields beyond the minimum required for the declared task.
DPDP S.9
Children's Data: Any processing path where a minor's data could be involved triggers automatic circuit-breaker regardless of other policy settings.
DPDP S.16
Data Fiduciary Duties: Agent cannot route personal data to unapproved third-party processors without explicit operator authorization in casa.yaml.

Custom Rego Policies
Open Policy Agent · Declarative · Hot-Reload · ENTERPRISE+ Tier

Write your own compliance rules in standard Rego. Edit a .rego file and the engine picks it up atomically without restart. Used to implement internal legal policies, sector-specific rules, or country-specific requirements not in the built-in frameworks.

Use case 1
SEBI regulations for Indian capital markets — block agents from calling trading APIs without dual-approval workflow in the session context.
Use case 2
Internal legal policy — block any agent from reading contracts folder unless user role is "legal_team" in the session JWT claims.
Use case 3
HIPAA mapping — custom PII patterns for PHI, enforce US data residency, block any tool call to a non-HIPAA-BAA-signed service endpoint.
Regopolicies/custom_internal.rego — example
package casa.ai.custom # Block contract reads unless user is legal_team unapproved_tool_call if { some call in input.tool_calls call.resource_path == "/contracts/" input.session.user_role != "legal_team" } # Block trading API without dual approval unapproved_tool_call if { some call in input.tool_calls call.tool_name == "execute_trade" not input.session.dual_approval_obtained } # Custom PII pattern — internal employee ID pii_detected if { regex.match( `EMP-[0-9]{6}`, input.agent_payload.prompt, ) }

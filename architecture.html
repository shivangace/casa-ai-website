The Security Gap

Traditional tools were built for deterministic software.

AI agents are non-deterministic. They reason, plan, and act — creating a massive unmonitored attack surface between the user's prompt and the agent's final action that WAFs, SIEMs, and API gateways were never designed to see.

The invisible attack: An agent retrieves a document. Its intermediate Thought-Action-Observation reasoning chain — never visible to any API gateway — contains a PAN card number. The agent's final API response looks perfectly clean. Every existing security tool missed the leak completely.

A
Context & Reasoning Tracker

The most novel module in CASA-AI and the layer no competing product has. Intercepts raw Server-Sent Events token streams from any OpenAI-compatible LLM, reassembles fragmented chunks into complete Thought-Action-Observation steps, and builds a live intent graph per session. This is where real leaks happen — and where every other security tool is completely blind.

SSE Token Reassembly

Chunks arrive as partial strings. A PAN number like "ABCDE1234F" may split across 3–4 chunks. The interceptor buffers and reassembles before running any regex — catching leaks that line-by-line scanners miss completely.

TAO Loop Classification

Each reassembled line is classified as Thought / Action / Observation and added to the session's in-memory intent graph. The compliance engine evaluates the full graph — not isolated lines in isolation.

MCP Tool Call Interception

Model Context Protocol tool calls are intercepted before dispatch. Tool name, provider country, and parameters are extracted and evaluated against the approved_tools allowlist in casa.yaml.

Zero-Copy Pass-Through

Clean tokens pass through with <2ms overhead. The engine is invisible on the happy path — decisive only when a violation fires. SSE connection is severed mid-stream on breach detection.

Go internal/proxy/stream_interceptor.go
// ProcessChunk — called for every SSE chunk from the LLM provider. // Returns false when a violation fires and the stream must be severed. func (s *StreamInterceptor) ProcessChunk(chunk []byte) (bool, error) { s.buf.Write(chunk) lines := s.extractCompleteLines() for _, line := range lines { step := s.classifyLine(line) // → Thought | Action | Observation s.graph.AddReasoningStep(step) // add to session intent graph verdict, err := s.engine.Evaluate(s.ctx, s.graph.Snapshot()) if err != nil { return false, fmt.Errorf("eval: %w", err) } if !verdict.Allow { // Fire circuit-breaker synchronously — sever stream, revoke creds _ = s.breaker.Fire(s.ctx, FireParams{ SessionID: s.sessionID, Violations: verdict.Violations, }) return false, nil // caller drops TCP connection immediately } } return true, nil }

C
Automated Circuit-Breaker

When a breach fires, the circuit-breaker executes synchronously — not advisory, not logged-and-continue. The SSE stream is severed, IAM credentials are invalidated via real cloud APIs, and a signed webhook alert is dispatched. All four steps are independent — a failed IAM revocation never prevents session freeze. Tested live against real AWS, not simulated.

AWS IAM Revocation — Live Tested

PutRolePolicy attaches a deny-all inline policy with DateLessThan on aws:TokenIssueTime. All sessions before the breach timestamp are immediately invalid. Tested live against AWS account 083334184188 — confirmed in 3.0 seconds.

GCP Service Account Disable

GCP IAM API disables the service account bound to the agent's Workload Identity. normalizeGCPServiceAccountName() handles both bare email and full resource name formats. Independent unit tests — all passing.

Azure Graph API Revocation

Two steps: revokeSignInSessions (invalidates refresh tokens) + accountEnabled=false (blocks new token issuance). Microsoft Graph API with HMAC-SHA256 signed Bearer token. Code complete, Azure tenant test pending.

HMAC-Signed Webhook Alerts

On breach, a JSON payload signed with HMAC-SHA256 is POSTed to the operator's configured endpoint. VerifyWebhookSignature() lets receiving systems authenticate that the alert came from CASA-AI — wrong secret = rejected, tampered payload = rejected.

// AWS-recommended DateLessThan condition — invalidates all existing sessions const revokePolicy = `{ "Version": "2012-10-17", "Statement": [{ "Effect": "Deny", "Action": "*", "Resource": "*", "Condition": { "DateLessThan": { "aws:TokenIssueTime": "%s" } } }] }` // Revoke — called synchronously by the circuit-breaker on breach detection. // All sessions issued BEFORE cutoff timestamp are immediately denied. func (r *AWSCredentialRevoker) Revoke( ctx context.Context, roleARN string, ) error { roleName := extractRoleName(roleARN) cutoff := time.Now().UTC().Format(time.RFC3339) policy := fmt.Sprintf(revokePolicy, cutoff) _, err := r.client.PutRolePolicy(ctx, &iam.PutRolePolicyInput{ RoleName: aws.String(roleName), PolicyName: aws.String("casa-ai-circuit-breaker-revoke"), PolicyDocument: aws.String(policy), }) if err != nil { return fmt.Errorf("aws revoke PutRolePolicy: %w", err) } return nil // Live tested: 3.0s · account 083334184188 · policy attached & verified }
